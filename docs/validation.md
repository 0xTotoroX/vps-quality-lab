# Release validation

Validated on 2026-09-12 for v0.1.0. The private live evidence is intentionally excluded from this repository and release archives.

- **Local automated checks:** 48 tests passed on macOS with Python 3.13.15; Ruff passed. Coverage includes subprocess CLI output/exits, input secrecy, host-key rejection, preservation of multiple authorized keys, concurrent-change refusal, failed fresh-key verification and policy rollback, node bundle repair, wrong exits, HTTP failures/incomplete transfers, evidence conflicts and interruption/resume. Installer failure tests prove that a partially copied binary does not suppress installation retry and that pending node keys are reused. Unowned services and changed deployment requests are rejected.
- **Real existing-server path:** Debian 12 with the existing Xray service. Automatic dedicated SSH key setup and a fresh OpenSSH BatchMode connection succeeded. The initially disabled public-key policy was enabled for the existing user with syntax/effective-policy checks and original-file backups. Existing password/root/port policy and Xray service were preserved. Adoption, URI/QR output, independent REALITY handshake, two-source egress checks before/after HTTP measurements, inventory, terminal capture and report export completed. The existing Shadowrocket node's relevant fields matched; its own loopback listener also passed both egress checks without changing the selected route.
- **Real measurement bounds:** two samples per target, 1 MB downloads/uploads, three parallel connections, 25-second request limit. These small smoke-test samples verify behavior; they are not an all-day capacity or account-safety assessment. The HTTP stage completed; IPQuality remained partial because terminal IPQS was 75 while JSON was `null`. NetQuality remained partial after process creation failed inside the bounded 1 CPU/512 MB/256-task environment. Its low-data mode intentionally skipped Speedtest/iperf throughput. Neither failure is treated as a VPS/network quality score. Original ANSI and JSON are preserved; updated interpretation is separately recorded.
- **Distribution and reporting:** wheel, source archive and Skill ZIP are produced with explicit inclusion rules and SHA256SUMS. A clean virtual environment installed the wheel with screenshot extras and ran machine-mode commands. Chromium rendered actual ANSI with xterm.js colors; the final report images were visually inspected. The report exports original images separately from credential-bearing node files. The dedicated Skill passed validation and an independent forward test.
- **Limits:** a fresh server installation/activation has not been exercised end to end on a disposable Debian/Ubuntu host. Generated configuration did pass the real Xray 26.3.27 native configuration check; installer interruption/recovery uses test doubles. Linux client behavior is covered by CI contracts, not this live macOS run. CPU/disk stress, complete return routes, UDP, account login/AI dialogue, video playback, multiple time windows and optional upstream/airport routing remain unverified in the live release smoke test.

GitHub Actions runs the same contract suite and package installation on Ubuntu/macOS with Python 3.11/3.13. Consult the repository's Actions result for the corresponding commit rather than inferring remote CI success from local checks.
